# Bank customer forms

A small Streamlit app for generating customer forms and transaction statements from PostgreSQL data. Select a customer and document template, preview the result, and download it as RTF or PDF. The app also includes company summaries and a converter for files generated by this app.

## Stack

- Python 3.12+
- Streamlit
- PostgreSQL 17 through `psycopg`
- ReportLab for PDF generation; hand-built RTF output
- `pdfplumber` for reading PDFs in the converter

## Setup

Start PostgreSQL and create the database:

```bash
docker run -d --name bank_forms_db -e POSTGRES_USER=admin -e POSTGRES_PASSWORD='<your password>' -e POSTGRES_DB=bank_forms -p 5432:5432 postgres:17
```

Configure the connection (or copy `.env.example` to `.env` and set these values):

```bash
export PGHOST=localhost
export PGPORT=5432
export PGUSER=admin
export PGPASSWORD='<your password>'
export PGDATABASE=bank_forms
```

Install and initialize from the repository root:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
psql -h "$PGHOST" -U "$PGUSER" -d "$PGDATABASE" -f sql/setup.sql
python -m scripts.seed_templates
```

`sql/setup.sql` creates the companies, customers, transactions, and template tables and inserts sample companies/customers. `scripts/seed_templates.py` imports JSON files from `document_templates/`. Template files are named `<name>.v<version>.json`; imported versions are not overwritten. To publish an updated template, add a new versioned file, then rerun the seed command. `scripts/seed_demo.py` can replace the sample customers and transactions with its deterministic demo dataset; it is destructive to those tables, so use it only on a development database.

## Run

```bash
streamlit run app.py
```

For Armenian text in PDFs, install the DejaVu Sans font files at `/usr/share/fonts/truetype/dejavu/` (on Ubuntu: `sudo apt install fonts-dejavu-core`).

## Code map

- `app.py`: customer form UI and converter.
- `pages/companies.py`: company totals, customer lookup, transaction history.
- `pages/statements.py`: filtered transaction statement UI.
- `db.py` and `sql/`: database access and SQL statements.
- `documents.py`: document preparation, RTF/PDF rendering, previews, and conversion.
- `document_templates/`: versioned JSON templates for generic customer forms.
- `scripts/`: database/demo utilities and template import.

## Checks

Run the regression tests with:

```bash
python -m unittest discover -s tests
```

The file converter is intended for RTF/PDF documents produced by this app; PDF layout reconstruction is heuristic and may not preserve arbitrary external documents.
